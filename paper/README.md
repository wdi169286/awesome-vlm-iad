# Paper Companion

This directory maps the survey manuscript to reusable evidence records. It separates values reported by prior work from results generated by the controlled studies.

The submitted manuscript itself is intentionally not hosted here before acceptance. This directory contains navigation and public companion records only.

## Evidence Layers

| Layer | Purpose | Public record |
| --- | --- | --- |
| Literature catalogue | Identify methods, datasets, code, and evidence paths | [papers.md](../papers.md), [data/papers.yml](../data/papers.yml) |
| Source-reported results | Preserve displayed values with their source and native protocol | compact tables to be added after manuscript freeze |
| Controlled studies | Document E1--E4 interventions, validity checks, and admitted aggregates | [experiments](../experiments/README.md), [result records](../results/README.md) |
| Model provenance | Record official weights, locally trained checkpoints, and released-output analyses | [MODEL_ZOO.md](../MODEL_ZOO.md), [data/checkpoints.yml](../data/checkpoints.yml) |

## Release Principle

The repository will expose compact tables, configs, manifests, and scripts needed to understand or reproduce a paper claim. It will not mirror datasets, third-party checkpoints, optimizer states, or large caches. Results still undergoing a pre-specified validity check remain marked pending rather than appearing in a final aggregate.

## Current Release State

The final PointAD factorial and the GS-CLIP endpoint-path audit are frozen under [results/E4](../results/E4/README.md). Study-trained checkpoint links and checksums are maintained in the [model zoo](../MODEL_ZOO.md) and its [machine-readable registry](../data/checkpoints.yml).
