# E4: Auxiliary and Compositional Evidence

**Question.** When does an auxiliary modality, refinement module, reasoning checkpoint, or tool path improve, fail, or harm an inspection decision?

**Interventions.** Geometry removal/corruption, proposal-to-mask interaction, matched reasoning-checkpoint comparison, and direct-versus-tool-fused output analysis.

**Methods represented in admitted analyses.** BTP-3DAD, PointAD, SAA+, AnomalyR1, AD-Copilot, and AnomalyClaw.

**Completed boundary study.** GS-CLIP completed all 21 clean, depth-rebinding, and inverse-recovery units, but failed the registered endpoint-path gate: its released evaluator does not use the rebound depth patch features to construct the registered point/fused localization maps. The compact audit is retained, but no GS-CLIP numerical effect is admitted.

**Primary readouts.** Each method retains its native task endpoint; heterogeneous endpoints are not pooled.

PointAD's complete three-train-class RGB-identity $\times$ point--pixel-correspondence factorial is admitted as an implementation-scoped analysis. The [frozen result bundle](../../results/E4/README.md) contains its full aggregate and final audit, the GS-CLIP exclusion audit, and the manuscript-facing effect table. The aggregation script is retained beside this README.
